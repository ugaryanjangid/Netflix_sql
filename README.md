# 🎬 Netflix Data Analysis Using SQL

## 📌 Project Overview

This project focuses on analyzing the Netflix Movies and TV Shows dataset using MySQL. The objective is to solve real-world business problems by writing SQL queries and extracting meaningful insights from the data.

The project covers SQL fundamentals as well as intermediate concepts including filtering, aggregation, ranking, string functions, date functions, subqueries, Common Table Expressions (CTEs), and window functions.

---

## 🎯 Objectives

- Analyze Netflix content using SQL
- Explore trends in Movies and TV Shows
- Identify popular genres, ratings, directors, and countries
- Solve real-world business questions using SQL
- Strengthen SQL problem-solving and analytical skills

## 🗂️ Dataset Information

The dataset contains information about Netflix Movies and TV Shows.

| Column Name | Data Type | Description |
|-------------|-----------|-------------|
| show_id | VARCHAR(6) | Unique content ID |
| type | VARCHAR(10) | Movie or TV Show |
| title | VARCHAR(130) | Title of the content |
| director | VARCHAR(230) | Director name |
| cast | VARCHAR(800) | Cast members |
| country | VARCHAR(150) | Country of production |
| date_added | VARCHAR(50) | Date when content was added to Netflix |
| release_year | INT | Original release year |
| rating | VARCHAR(10) | Content rating |
| duration | VARCHAR(15) | Movie duration or TV Show seasons |
| listed_in | VARCHAR(100) | Genre(s) |
| description | VARCHAR(300) | Short description of the content |
